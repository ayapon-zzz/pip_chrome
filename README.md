# pip_chrome

U-NEXT で次のエピソードが自動再生されたとき、ピクチャーインピクチャー（PiP）を新しい動画へ自動で引き継ぐ Chrome 拡張です。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. すでに開いている U-NEXT のタブは再読み込みする

## 使い方

いつも通り U-NEXT の動画を PiP にするだけです。次のエピソードが再生され始めると、PiP ウィンドウがそのまま新しい動画に切り替わります。

PiP ウィンドウを自分で閉じた場合は、再度 PiP にするまで何もしません。

## 仕組み

- `content.js`: PiP 中の動画が終了・破棄・一時停止され、別の動画（60 秒以上のもの）が再生を始めたら、その動画で `requestPictureInPicture()` を呼びます。PiP ウィンドウが残っている間は、ユーザー操作なしで別の動画へ切り替えられます。
- `page.js`: サイト側がユーザー操作なしで `exitPictureInPicture()` を呼んだ場合に無視し、PiP ウィンドウが閉じないようにします。

## 制限

- PiP ウィンドウが完全に閉じてしまった後は、Chrome の制約でユーザー操作なしに開き直せません。
- ページ全体が再読み込みされる遷移では引き継げません。

うまく動かないときは、U-NEXT のタブで DevTools のコンソールを開き、`[U-NEXT PiP Keeper]` のログ（「詳細」レベルも表示）を確認してください。
